## R-A：跨家族组合（ep120 + EMA 0.99 + top-3 of 10）

### 通过了全部五条条件

| 条件 | 实测 |
|---|---|
| ΔW ≥ 标定地板 +0.002 | **+0.00788**（实测噪声上限 0.0015419 的 5.1 倍） |
| ΔW_noS2 ≥ +0.002 | +0.00729 |
| 无模块 Δ 为负且 CI 排除 0 | **六个模块全部改善，无一变差** |
| Gate-Z 不触发 | S1 仅占 ΔW 的 30.9%，最大贡献是 FC 的 39.4% |
| Gate-R1F | 不适用（直接训练产物，无 R1 成分） |

验证集 RMSE 0.417717（项目最佳）、FC 0.503782（首次破 0.50）。
十个种子的完整 RMSE 表见 `outputs/p4_ra/top3_selection.json`。

### 为什么仍然不采纳

采纳前做了一次常规核对：**被采纳的配置在提交链上到底表现如何。**

项目里有两条并存的 fit-seed 约定，都早于本轮：
- 验证实验链 `scripts/a2b_train_variants.py`：`fit_seed = seed + 9000`
- 提交链 `scripts/train.py` / `make_mask_compound_3seed_submission.py`：`fit_seed = seed`

R-A 的全部证据来自前者。把**同一配置、同样三个固定种子** {20260810, 3407, 42} 放到两条链上分别测：

| | ep40 基线 | ep120 + EMA 0.99 | 配置效应 |
|---|---:|---:|---:|
| a2b 链（fit_seed = seed + 9000） | 0.420258878 | 0.418919577 | **−0.001339（更好）** |
| 提交链（fit_seed = seed） | 0.421007924 | 0.423181721 | **+0.002174（更差）** |

**同一配置、同样种子，只换 fit_seed 偏移，配置效应翻符号。**

按选出的三个种子 {20260810, 3407, 7} 在提交链上重训，验证 RMSE 为 **0.428203895**，
比提交链基线 0.421007924 差 **+0.0072**——因为那三个种子是为另一个种子族选出来的，
在这个族里只是一组任意三元组。

拆开来看（均在 a2b 链上）：配置效应 −0.001339、选择效应 −0.001202，各占一半。
而配置效应本身在换族后就翻转了，说明 **+0.00788 不是配置的属性，是一个未被测量的自由度的属性。**

### 事后确证：十种子配对比较（零训练成本，决定性）

推翻发生后，用**已有产物**做了一次配对检验，不需要任何新训练：
`outputs/p1_multiseed/seed*/ensemble_metrics.json`（ep40）与
`outputs/p4_ra/seed*/ensemble_metrics.json`（ep120+EMA）本就覆盖同一族的同样十个种子。
按种子配对，逐一比较：

| seed | ep40 | ep120+EMA | Δ（正 = 更差） |
|---|---:|---:|---:|
| 20260810 | 0.421664 | 0.422602 | +0.000938 |
| 3407 | 0.425222 | 0.424860 | −0.000363 |
| 1234 | 0.425746 | 0.430026 | +0.004280 |
| 5678 | 0.426998 | 0.431853 | +0.004855 |
| 42 | 0.429855 | 0.431922 | +0.002067 |
| 91011 | 0.430257 | 0.432842 | +0.002585 |
| 2024 | 0.430793 | 0.432859 | +0.002066 |
| 7 | 0.431863 | 0.426646 | −0.005217 |
| 20260903 | 0.433109 | 0.431943 | −0.001166 |
| 31337 | 0.433191 | 0.437321 | +0.004130 |

| 统计量 | 值 |
|---|---:|
| 改善的种子数 | **3 / 10** |
| 配对差均值 | **+0.001418（ep120+EMA 更差）** |
| 配对差标准差 / 标准误 | 0.003049 / 0.000964 |
| 配对 t（df = 9） | +1.470（\|t\| > 2.262 才 p < 0.05） |
| 符号检验 p | 0.344 |
| 单种子均值 | ep40 0.428870 ｜ ep120+EMA 0.430287 |
| 单种子标准差 | ep40 0.003811 ｜ ep120+EMA 0.004376 |

**方向本身就是错的**：ep120+EMA 的配对差均值为正（更差），且无论 t 检验还是符号检验都不显著。
这条杠杆不是"效应太小测不出"，是**测得出的部分指向变差**。

这张表还解释了 top-3 选择的机制。在 ep40 下，seed 7 排第 **8/10**（0.431863）；在 ep120+EMA 下它排第
**3/10**（0.426646）——唯一一个大幅改善的种子。10 选 3 恰好把它选中，于是"配置效应"和"该种子在该配置下
的运气"被绑在一起，无法分离。之前测得的 −0.001339 配置效应，本质是十个种子里排名靠前那三个的抽样运气；
十选三又叠了第二层选择偏倚。**两层都是随机性，不是配置。**

→ 结论从"存疑，跨族复核推翻"升级为**"确证为假象"**。ep120 + EMA 这条杠杆就此关闭，不再复议。

## R-B：ΔW 检测地板的实证标定，及其自身的局限

三个互不重叠的同配置 3-seed 集成（E1 复现了 P1 top3 的 0.418924314，逐位一致）：

| | ΔW | ΔW_noS2 |
|---|---:|---:|
| null_E1 | +0.0014408 | +0.0019464 |
| null_E2 | −0.0015419 | −0.0001229 |
| null_E3 | −0.0012418 | +0.0012319 |

`max|ΔW| = 0.0015419` → **标定地板 +0.002**。命中预注册结局 `floor_smaller`：
legacy 的 +0.010（推法 `0.053 × 0.20`）把 S1 的 6 聚类效应量地板误用到 2,806 行的加权和上，
是类别错误，过保守约 5 倍。

**但 R-B 自身有一个本轮才暴露的局限**：三个 null 集成全部来自 `outputs/p1_multiseed/`，
即**同一个种子族**（fit_seed = seed + 9000）。它测的是族内换种子的噪声，**没有跨越 fit-seed 约定这个自由度**。
而 R-A 复核测出的跨族效应（−0.0013 vs +0.0022）与族内噪声同量级。

→ **检测地板必须跨越所有未被测量的自由度，而不只是你恰好变动的那一个。** 这是本轮最重要的方法学结论。

## R-C：低速率菌株掩码（干净负结果）

假说：`mask_compound` 的 `do_strain = False`，菌株 `<UNK>` 从不收梯度，正是 A2 当初要解决的病理；
历史负结果「双字段掩码 +0.015」是在 mask_p = 0.25 下测的，可能只是速率太狠。

新增 `--strain-mask-p` 标志，默认 `None` 保持向后兼容。落地前先过 bit-identity 回归：
默认值下整棵指标树 116 个数值指标递归比对，**max|Δ| = 0.0**，`log2_rmse = 0.42166375888106966`
与 `outputs/p1_multiseed/seed20260810` 逐位一致。

| 速率 | 3-seed 集成 RMSE | vs 基线 0.420259 | ΔW |
|---|---:|---:|---:|
| 0.05 | 0.423906 | +0.0037 | −0.00084 |
| 0.10 | 0.432162 | +0.0119 | −0.00575 |

**即使 0.05 也变差，且随速率单调恶化。** 假说被证伪：问题不在速率太狠，菌株掩码这个方向本身不成立。
六个 run 的 `metrics.json` 均正确记录了 `strain_mask_p`（非 null），排除了空转。

## 顺带发现：S1 的 6 聚类 bootstrap 有可观假阳性率

R-B 的 null_E3（**什么都没改，只换种子**）给出 ΔS1 = +0.016275，CI [+0.004972, +0.036964]，**排除 0**。
与历史上被称为"唯一有效候选"的 R1 凸混合对比：

| | ΔS1 | CI95 | 排除 0 |
|---|---:|---|---|
| null_E3（纯种子噪声） | +0.016275 | [+0.004972, +0.036964] | 是 |
| r1_convex_w010 | +0.021908 | [+0.007973, +0.038528] | 是 |
| r1_convex_w005 | +0.012145 | [+0.005161, +0.020515] | 是 |

**两个区间几乎重合，w005 的效应量甚至小于纯噪声那一抽。**
→ "CI 不含 0" 不能作为 S1 上效应为真的证据。
→ 这反过来**追溯性地证明 0.053 效应量地板是对的**：它拦下了一个显著性检验误判为显著的候选。

两个地板，一对一错，现在都有实测支撑：

| 地板 | 判定 | 依据 |
|---|---|---|
| S1 效应量地板 0.053 | **正确，保留** | 拦下了 CI 检验误判为显著的候选 |
| ΔW 地板 +0.010 | 推导是类别错误 | 族内标定为 +0.002；但族内标定本身不足（见 R-B 局限） |
