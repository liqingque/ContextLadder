# 科学发现与方案说明报告

**上下文阶梯 ContextLadder —— 面向未见扰动与未见菌株的虚拟酵母蛋白组预测**
GOAI 赛道三 · 虚拟细胞方向 ｜ 团队 TorchDragon（李晓蒙、徐逸飞）｜ 2026-09-01

---

## 摘要

我们没有先造模型，而是先问了一个问题：**这个任务的分数，具体在测什么？**

答案改变了我们做方案的方式。占官方权重 20% 的"上下文均值残差"模块，是整份赛题里最直接
对应"零样本扰动泛化"的一项。我们对它做了一次机械检查，发现：**目前所有可得的模型，对未见
化合物只发出一个向量——每个上下文一个，与是哪一种化合物无关。** 该模块的得分完全来自所有
化合物共享的分量，没有任何化合物特异信息参与。

这不是我们模型的缺陷，是被测的五个候选（含两类官方基线家族构造）与更早八个不同架构的共同
性质。随后我们量化了它的边界：训练化合物残差的线性张成里存在 ρ≈0.267 的可达方向（**容量够**），
稠密与稀疏解码器的差在四个通道上全为负（**解码器不是瓶颈**），而所有可构造的化合物表征通道
都打不过负对照（**缺的是内容**）。

方法层面，这条测量把设计问题从"如何预测新化合物的效应"改写成"**在没有证据时如何优雅地不知道**"。
ContextLadder 是这条约束的实现：两条分支各是同一原则的一次实例化，每一条都挂着一个先于它做出
的测量，以及一个把它证伪的对照。

全部工作在预注册纪律下完成：每阶段判据在数据进入前冻结并记录 SHA-256，执行期未移动任何阈值；
十五族方法分支被证伪并如实记录，其中三条是我们本可以受益却没有动手的自证记录。

## 一、发现一：20% 权重的模块上，没有模型贡献化合物信息

### 1.1 测量

在冻结验证集上，取每个上下文块内**携带不同未见化合物**的行对，比较它们的预测蛋白组向量：

| 场景 | 行数 | 含多化合物的上下文 | 跨化合物行对 | 逐位相同 | max\|Δ\| |
|---|---:|---:|---:|---:|---:|
| S1（已见菌株 + 未见化合物） | 1,065 | 379 | 991 | **991** | **0.000e+00** |
| S3（双重未知） | 269 | 96 | 250 | **250** | **0.000e+00** |

五个候选——本方案、两个全局梯度提升基线、一个分场景低秩统计基线、一个分场景梯度提升基线
——**结果完全一致**。更早一轮在八个不同架构（FiLM / HCCE / CA-HCCE / 逐蛋白 EB 校准等）上
得到相同结论。

一项**独立且更早**的测量指向同一处：剥离 Δ_pred 与 Δ_true 共享的 −y_control 项后，用模型
内部差分度量纯粹的化合物特异效应，已见化合物 **0.175**、未见化合物仅 **0.042**。

### 1.2 一条方法学更正

我们最初用化合物标签置换检验来测这件事，得到 p = 1.0，并一度把它写成"经典基线也无化合物信息"
的证据。复核时发现该检验在此处**零功效**：`null_sd = 0.0`——200 次置换里 null 的方差恰好为零。
原因是结构性的：所有未见化合物本就映射到同一个 unknown token，置换不改变任何输入。

**p = 1.0 是恒等式，不是结果。** 我们撤回了原表述，改按其本来面目报告：这是一个**不变性恒等式**，
它证明预测是化合物不变的，但它**不为"化合物信息不可得"提供任何独立证据**。后者的证据在第四节。

这条更正本身值得留在报告里：一个零方差的置换检验看起来像一个通过了的显著性检验，很容易被
当成结论。

### 1.3 三条必要的限定

1. **不是"我们的模型不行"。** 这是所有被测模型的共同性质，包括官方基线家族。在化合物信息
   确实可用的场景上，本方案是平凡基线的数倍（第五节）。
2. **不是统计检验的结论。** 见 1.2。
3. **不说明化合物信息不可能获得。** 那需要另外的证据，见第四节。

### 1.4 对领域的判断

模型在 S1 上拿到的 0.203387 不是"对新药机制的预测"，而是"对该批次共享响应与对照锚定的预测
质量"，只是通过残差模块的算式表现出来。

这有一个可直接验证的推论，我们验证了它：**若 S1 只反映共享分量的质量，则模型间的 S1 差距应
等同于绝对预测质量的差距，与化合物建模能力无关。** 实测符合——五个候选的化合物信息同为零，
而 S1 从 0.073488 到 0.203387 相差近三倍，这个差距完全由绝对保真度与对照锚定质量决定。

**因此：S1 这个 20% 权重的模块目前测的是"共享上下文响应 + 对照锚定"的预测质量，不是"新化合物
特异响应"的能力。** 在有模型能通过第四节的表征门槛之前，该模块的排名不应被解读为零样本机制
泛化能力的排名。

## 二、发现二：选择目标不等于评分目标

官方 25% 的 FC 模块要求把处理样本匹配到同来源、菌株、培养基、温度、时间、仪器、板号下的
DMSO 或 Water 对照。**对照池从哪里取，赛题文本未作限定，而这个选择会静默改变被评估的样本集合。**

以官方口径（对照池 = `train | val`）计算，验证集共 **2,806** 个匹配行：seen 139 / S1 1,065 /
S2 1,333 / S3 269。若改用**仅训练池**的对照，S2 的 1,333 行与 S3 的 269 行会全部失去匹配对照
而被丢弃——**共 1,602 行，占 57.1%**，恰好是两个最难、得分最低的场景。

**任何在训练池对照下做的模型选择，都对 57% 的匹配行是盲的。** 我们自己在 2026-08-13 至 08-15
的多轮 gate 就踩在这个坑里，是在重建官方口径评估器时才发现的。

两条配套发现：

- **只看单一 RMSE 会错排相关性模块。** 八个候选中 CA-HCCE 的 FC 全体分数最高（0.491982），
  但 S1 排名倒数第三（0.166947）。
- **μ_ctx 的上下文键被我们误判为"赛题未定义"，实际上赛题定义了它**："剔除同一菌株/培养基/
  温度/时间/冻结批次下的共享药物响应分量"——不含来源、不含仪器。把唯一未绑定到列的"冻结批次"
  分别绑到板号与来源两种读法后实测，**两者与完整严格键给出逐位相同的结果**（S1 = 0.203387，
  n = 1,059，八个候选全同）。因此 S1 的官方读数唯一确定；此前作为敏感性上界报告的生物学粒度
  数值 0.5512 **不是官方读法**，其表面增益是伪信号，我们不再引用。

这三件事对任何参赛队都适用，我们把评估器开源以便独立复核。

## 三、发现三：这个划分能验证什么、不能验证什么

**S1 侧**：验证集只有 **6 个未见化合物**，即 6 个聚类。聚类 bootstrap 标准差 0.0265，95% 区间
[0.139, 0.235]。任何小于约 **0.053** 的 S1 改动在这个划分上**不可判定**。我们把 0.053 冻结为
效应量地板，此后没有为任何候选下调过它。

代价是真实的：R1 凸混合是测过的八个候选中**唯一**改善 S1 的（w = 0.10 时 +0.02191，配对
bootstrap CI [+0.00797, +0.03853]，两种粒度同号，其余模块不退化），仍因 +0.0219 < 0.053 判 FAIL。

**S2 侧的问题更严重**：验证集只提供**一个**未见菌株（BAI），即单聚类；而测试集 **59.8%
（2,663/4,454）** 的行落在未见菌株上，主力未见菌株 **CRD 有 2,231 行，在 `train_val` 中一行都
没有**。因此在 BAI 上选出的任何菌株侧改动，对 CRD **没有任何泛化证据**——不是"证据弱"，是
"选择实体与评测实体不同"。我们据此关闭了整条菌株侧建模分支，并在所有加权判据中强制并列报告
去掉 S2 项的版本。

**这是 benchmark 设计层面的观察，不是抱怨。** 可操作含义：该划分能支持关于绝对保真度、FC 与
时间插值的结论；对于"未见菌株背景调制"这一 20% 权重的模块，它目前只能支持描述性报告，不能
支持模型选择。

## 四、发现四：缺的不是模型容量，是化合物表征

在 37 个训练化合物的**完全嵌套、无泄漏**留一交叉验证上测量（harness 用稀疏解码器逐位复现了
独立实现的参考值 0.005872 / −0.000727 / 0.4636，37 折泄漏断言全过；判据在任何真实数据进入
管线之前冻结）。

**容量够。** 训练化合物残差的线性张成（全张成 k = 36）中存在与目标对齐 **ρ_oracle = 0.2671**
的方向，聚类 bootstrap 单侧 95% 上界 0.2941（严格粒度）/ 0.2706（生物粒度），**均高于 0.20 门槛**。

**解码器构造不是瓶颈。** "稠密低秩解码器 − 稀疏支撑解码器"的差在**四个通道上全部为负**
（−0.005 ~ −0.019）。

**缺的是内容。** 所有可构造的化合物表征通道都打不过负对照：

| 通道 | ρ̄ | 95% CI |
|---|---:|---|
| φ_TXT（机理文本嵌入，预注册主通道） | 0.0268 | [−0.0117, +0.0664] |
| φ_SSPS（结构化机理先验，消融） | −0.0325 | [−0.0727, +0.0126] |
| Tanimoto 化学相似度（构造对照） | −0.0148 | [−0.0589, +0.0392] |
| 随机嵌入（负对照） | −0.0250 | [−0.0643, +0.0183] |

主通道经 maxT 多重性校正后同样不显著（观测 |均值| 0.0346 < 临界 0.0638）。
（以上四项出自 DCB-40 执行报告。）

**稀疏先验这一族在数学上已经关闭。** 覆盖中位 58 个蛋白的稀疏机制先验，**即使方向全部正确**，
全向量相关的结构上限也只有 **0.0491**；其中约一半（0.027）来自"稀疏且随便哪里符号对"本身，
与机制知识无关。同族实测先验的 Gate-0 得分为 ρ̄ = 0.0059，CI 含 0。（这两项出自 M0 模块评估
报告，与上表不同源。）

**四条合起来给出一条可被接续的定量结论：**

> 要让 20% 的 S1 模块产生真实的化合物特异信号，需要**覆盖 4,422 个蛋白中相当大比例、且方向
> 优于随机的稠密先验**。换编码器无效（四个通道都试过），换解码器无效（稠密−稀疏全负），做更
> 精细的稀疏机制先验在数学上不可能达标（上限 0.049 < 地板 0.053）。**oracle 0.267 与可实现
> 0.03 之间近十倍的差距，只能来自化合物表征本身。**

**必须写明的限定**：上述 ρ 在留出训练化合物上测得，而那是训练化学空间内的**插值**。实测 6 个
验证集未见化合物中有 3 个落在训练集内部最近邻距离分布的 p90 之外，其中 Sulfometuron methyl 与
Pentamidine isethionate 位于 **100 分位**——比任何一对训练化合物之间都更远。**因此 0.0268 对
真实的 S1 任务而言仍然偏乐观。**

## 五、方法：ContextLadder 是上述测量的推论

第一节与第四节合起来给出一个明确的设计约束：**对一个未见化合物，模型没有任何可用的化合物特异
信息**（不是没做，是四个通道都试过、都打不过负对照）。在这个前提下，唯一有证据支持的行为是
**退回到更粗的一级先验**，而不是让一个从未训练过的化合物 ID 去驱动输出。

「阶梯」是这条约束的实现，两条分支各是同一原则的一次实例化。

### 5.1 测量分支的分层收缩：先有测量，后有设计

基线阶段有一个意外结果：**只用测量上下文**（来源/仪器/板号）的 Ridge 达到 abs-PCC **0.982272**，
而只用生物上下文的 Ridge 只有 **0.962347**，两者合并的完整 Ridge 是 **0.984998**。测量批次
几乎解释了全部可解释方差——典型的 batch shortcut 风险：模型容易退化成"板号查表器"，遇到未见板
即崩溃。

回应不是丢掉板号（会损失大量真实信号），而是**把板号建模为来源/仪器之上的收缩残差**：见过的板
享有自己的偏移，未见的板自动退回仪器/来源一级，退回是结构性的，不需要任何运行时分支。

### 5.2 化合物掩码：把"不知道"从随机向量变成学出来的状态

未见化合物落到保留的 `<UNK>` 槽位，而该槽位的嵌入在训练中**从未收到梯度**——它是一个随机
初始化的陌生向量，会驱动模型输出任意扰动信号。

我们先用一个不需要重训的探针定位该机制：把冻结检查点里的 `<UNK>` 嵌入替换为类别均值。结果
**方向对但不稳健**——化合物侧一个种子的未见化合物子集 RMSE 从 0.378413 降到 0.366050（−0.0124），
另两个种子只有 −0.0001 / −0.0018；**菌株侧三个种子全部退化**。

结论：随机 `<UNK>` 确实在造成损害，但**事后打补丁不行，这个回退状态必须被训练出来**。于是：
训练时以 25% 概率把化合物 token 掩码为 `<UNK>`，标签不变。

**该设计有方向性、可被证伪，不是随手加的正则**，三条实测支撑：

| 变体 | 结果 | 说明 |
|---|---|---|
| 只掩码化合物（采纳） | 三种子全部优于不掩码基线；集成 RMSE **−0.003405** | 未见菌株子集 −0.003470、未见化合物子集 −0.001937，两个 OOD 子集同时改善 |
| **同时掩码化合物与菌株** | **RMSE +0.015（显著退化）** | 菌株特异性真实且可学，掩码它是破坏而非正则 |
| 事后均值替换 + 掩码训练 | 三种子全部退化（+0.0001~+0.0003） | 训练出的 `<UNK>` **严格支配**事后修补 |

中间一行是关键：若这只是"加了个 dropout"，掩码菌株应当同样有益。它没有。

### 5.3 双专家融合

分层结构对**已见实体**有代价——收缩削弱精确记忆。因此保留一个高容量 one-hot 专家，与分层专家
做固定 50/50 融合。三种子验证：legacy 专家 0.987670、HCCE 分层专家 0.987444、**50/50 融合
0.988140**——融合优于任一单专家，权重由仅使用训练数据的证据选定。

### 5.4 创新性主张的边界

我们不主张 FiLM、掩码训练或种子集成本身新颖。**主张的是：在一个已被证明"未见化合物信息不可得"
的任务上，把"如何优雅地不知道"当作一等设计目标，并给出可测量、可证伪的实现。** 上面每条设计
都挂着一个先于它做出的测量，以及一个把它证伪的对照。种子集成与契约固化属于工程卫生，不计入
创新点。

### 5.5 与赛题四个泛化场景的对应

赛题的四个泛化场景是同一回退原则的四次实例化。下表把场景、官方模块与权重、本方案机制和
验证集实测（数字与第六节同源）对齐，供按官方评分表核对：

| 赛题场景 | 官方模块 / 权重 | 本方案机制 | 验证集实测 |
|---|---|---|---|
| 未见化合物 | 上下文均值残差 S1 ｜ 20% | 训练时以 25% 概率掩码化合物 token，未见化合物落到**被训练过的** `<UNK>` 回退态而非随机向量（5.2 节） | S1 = 0.2034。该模块目前测的是共享上下文响应，全部候选（含官方基线家族）的化合物特异信号均为零（第一节） |
| 未见菌株 | 药物均值残差 S2 ｜ 20% | 未见菌株落入 `<UNK>` 槽位，由共享生物上下文（培养基/温度/时间）与测量上下文承担预测；菌株侧专门改进因验证集不可判定而整族关闭（第三节） | S2 = 0.4077（单聚类，仅描述性报告） |
| 双重未知 | 匹配对照 FC 全体 ｜ 25% | 上述两个回退同时生效，无任何未见实体专属参数被激活 | 含于 FC 全体 0.4914；S3 上下文内 250 个跨化合物行对逐位相同（第一节） |
| 时间插值 | 时间插值 FC ｜ 10% | 时间为连续协变量（z-score + 5 中心 RBF 基），不离散化，任意时刻自然插值 | 0.6717 = 平凡基线的 **2.9×**，全部场景中最高 |

| 绝对保真度 sample-PCC | 20% | **0.988598** | 0.953882 | — |
| 匹配对照 FC（全体） | 25% | **0.491355** | — | — |
| 上下文均值残差 S1 | 20% | 0.203387 | — | 见第一节 |
| 药物均值残差 S2 | 20% | 0.407705 | — | 单聚类，仅描述性 |

### 6.2 与官方基线家族的对照

我们实现并评测了官方基线家族的三种构造，判据在数据进入前冻结：

| 候选 | W | ΔW |
|---|---:|---:|
| 本方案 | **0.5218** | — |
| 分场景低秩统计 | 0.4471 | −0.0747 |
| 分场景梯度提升 | 0.4424 | −0.0794 |
| 全局梯度提升（PCA-128） | 0.4186 | −0.1032 |
| 全局梯度提升（PCA-64） | 0.4181 | −0.1037 |

采纳门槛为 ΔW ≥ +0.010（= 已冻结的 S1 效应量地板 0.053 × 该模块 0.20 权重），实测为反方向的
7.5×~10.4×；**六个加权模块无一例外全部更差**，S1 的四个差值经配对聚类 bootstrap 全部 CI 不含 0。

**限定必须写明**：这三种构造在一天内实现，梯度提升迭代上限 25/20，其中两种夹了 PCA 瓶颈，
分场景 GBDT 在 S1 路由上还把化合物列置零。可主张的是"**这三种具体构造被决定性劣于**"，
而非"梯度提升这条路走不通"。

**三条自证记录。** 它们是我们本可以受益却没有动手的地方：

- 第 8 族中若把 δ 定为 0.10，本轮结果会满足 REPRESENTATION GAP 的全部条件；但 δ 在看到任何 ρ
  之前已冻结为 0.05，**如实判 INDETERMINATE，未事后调整**。
- 第 11 族的 R1 是八个候选中唯一改善 20% 权重模块的，配对 bootstrap CI 不含 0、双粒度同号、
  其余模块不退化，**仍按 0.053 地板判 FAIL**，未进入提交线。后来证明这个决定是对的：一个**什么都没改、
  只换种子**的同配置集成给出 ΔS1 = +0.016275、CI [+0.004972, +0.036964]，**同样排除 0**，与 R1 的
  CI [+0.007973, +0.038528] 几乎重合。**S1 的 6 聚类 bootstrap 假阳性率可观，"CI 不含 0" 不足以证明效应为真**——
  效应量地板拦下了显著性检验放过的东西。
- 第 14 族是最彻底的一次：候选**通过了全部五条冻结采纳条件**，我们在采纳前做了一次不在预注册清单里的
  跨种子族复核，它推翻了采纳。随后用已有产物做的**十种子配对比较**把它钉死：**3/10 改善**、配对差均值
  **+0.001418（更差）**、配对 t = +1.470、符号检验 p = 0.344——方向本身就是错的。选出的 seed 7 在 ep40 下
  排第 8/10、在该配置下排第 3/10，十选三恰好选中它，配置效应与该种子的运气被绑死。
  **推论：检测地板必须跨越所有未被测量的自由度，而不只是你恰好变动的那一个。**
  我们标定的地板来自单一种子族内的 null，而跨族效应与它同量级。

## 八、复现情况

提交包支持"外部特征构建 → 训练 → 冻结推理 → prediction.csv"的完整复现，四条主命令可直接复制执行：

```bash
cd <代码材料包根目录>
conda activate tl   # 或 pip install -r requirements.txt；环境版本见 configs/env-spec.yaml

# 1) 外部特征构建 —— 本方案不使用任何外部特征，无需执行
python scripts/build_embeddings.py --output artifacts/embeddings

# 2) 从头训练最终模型（三个种子约 100 s；单张 RTX 3090，峰值显存 923 MiB）
python scripts/train.py \
  --metadata "input/WAYB_WAYC_metadata_train_val(1).csv" \
  --proteome input/WAYB_WAYC_proteome_raw_train_val.csv \
  --config configs/final.yaml --output-dir runs/final

# 3) 冻结模型推理，生成 prediction.csv（约 16 s；只读取测试 metadata，不读取任何蛋白组文件）
python scripts/predict.py \
  --metadata "input/WAYB_WAYC_metadata_test(1).csv" \
  --run-dir runs/final --output prediction.csv

# 4) 提交格式与数据边界校验（无需重跑训练）
python scripts/validate_submission.py --prediction prediction.csv --run-dir runs/final
```

在一个与开发仓无关的干净目录中实测（`reports/P0_REPRODUCTION_HARDENING_20260901.md`）：

| 项 | 结果 |
|---|---|
| 训练（三个种子，单张 RTX 3090） | 98.0 s，峰值显存 923 MiB |
| 推理 | 17.5 s |
| 全新 venv 按 `requirements_submission.txt` 安装 | exit 0，新环境内 `pytest tests/` 12 passed |
| **三个 checkpoint SHA-256** | 与随包 manifest 完全一致 |
| **`prediction.csv` SHA-256** | 与随包文件同一值——**逐字节可复现** |
| 提交格式校验 | PASS，九项硬检查全过 |
| 免数据契约测试 | 12 passed |

**测试蛋白组从未放入干净目录，四条命令仍全部成功**——`predict.py` 中不存在任何蛋白组读取路径，
测试对此有静态断言。

训练标签仅来自 `split_final == "train"` 的 5,920 行，`train.py` 内置硬断言使任何非 train 行进入
拟合索引即中止；蛋白过滤、类别映射、归一化、目标统计量全部只由训练划分拟合。

**已知限制**：官方未下发 4,422 列的 feature contract 文件，本包按规定规则实算并落盘列表与 SHA-256；
GPU 归约不保证跨硬件位确定，上述一致性均在同型号 RTX 3090 上取得。

## 九、开源情况

**仓库与许可**：全部代码、权重与清单随提交包分发，以逐文件 SHA-256 冻结（不依赖外部仓库
可达性）；**赛后将开源至公开仓库**，许可 CC BY-NC 4.0。最终模型**不使用任何外部数据**——只
消费官方样本元数据字段。外部公开资源只
出现在证伪实验中，逐条来源、版本、许可与校验和见 `external_data/source_manifest.json`，实体映射
（含未匹配、歧义与代理，共 65 行）见 `external_data/entity_mapping.csv`。

四件我们认为可被社区直接接续的工具：

1. **官方口径六模块评估器**——实现官方对照池、按实体可见性分层、四种 μ_ctx 粒度、化合物置换
   null、配对聚类 bootstrap。**任何参赛队都可以用它自查第二节那个 57% 的对照池问题。**
   实现上有一个值得记录的坑：μ 自身在"该上下文所有训练行都缺测"的蛋白上是 NaN，减去 μ 之后
   **必须重算观测掩码**，否则整行被判无效，S1 会被低估为 0.143 而不是 0.203。
2. **化合物不变性检查**——第一节诊断的通用实现，替代零功效的置换检验。任何新候选都应先过这一关
   再谈 S1 分数。
3. **嵌套无泄漏 LOCO harness**——37 折留一化合物，逐折泄漏断言，用独立实现逐位复现参考值。
4. **交叉拟合 OOF 基础设施与泄漏审计**——我们在此发现并修复了一个历史 both-fold 泄漏 bug
   （CSV writer 忽略了 train 掩码），修复后通过 5,920/5,920 恰好一次覆盖与双实体排他性检验。

## 十、我们没有做到的

- 20% 权重的 S1 模块，我们**没有**提供化合物特异信号；提供的是这件事的定量边界与所需条件。
- 20% 权重的 S2 模块，当前划分不支持模型选择，我们只作描述性报告。
- 第四节的边界以留出训练化合物测得，那是训练化学空间内的插值；对真实的未见化合物任务，我们给出
  的数仍然偏乐观。
- 为严格遵守数据使用约束，最终模型只用 5,920 行训练，未使用验证划分的 3,038 行（占 33.9%）。
  这在样本量上有明确代价，但保证复现核验口径干净。
